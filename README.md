# 拾题 · 英语自习室

在线访问：[拾题英语自习室](https://moyuhama.github.io/tijien/)。代码仓库：[moyuhama/tijien](https://github.com/moyuhama/tijien)。

网页提供 887 道题、128 篇双语阅读和 7 个小白带练课程。个人进度保存在当前浏览器，不上传到 GitHub。在线网址和本地文件的进度独立；从本地切换到在线版前，在「学习记录」导出进度，再到在线版导入。

## 本地使用

直接双击本文件夹里的 **打开英语自习室.html**，即可在浏览器使用。无需安装依赖、注册账号或联网。

网页、题库数据、入口、启动脚本和说明均集中在 `study-room` 文件夹。复制整个文件夹即可使用；上一级原始复习资料仅在重新导入题库时需要，日常刷题不依赖它们。

也可以双击本目录的 **启动本地服务.command**，通过固定地址 http://127.0.0.1:8765 使用。终端窗口需要保持打开，按 Control+C 停止。此方式需要 Python 3（当前电脑已有）。服务只监听本机。

建议长期固定使用一种打开方式、同一个浏览器。直接打开文件、localhost 和 127.0.0.1 的浏览器存储分别独立，不自动同步；换打开方式前在「学习记录」导出进度，再导入。

## 小白带练

从首页点击 **进入小白带练**，按顺序学 7 个小课：回应赞美、回应感谢、-ing 搭配、建议/要求句、wish 对现在的愿望、wish 对过去的遗憾、对过去的 if 假设。共覆盖现有题库中的 **65 道题**（7 道讲解例题 + 58 道练习题）。

每课先看口诀、适用条件和一个带中文句意的例题，再随机带提示练最多 5 题，然后独立做最多 5 道不同的同类题。例题不计入作答；题量少的课程按实际数量练习。每题确认后显示“先找线索 → 套用规则 → 排除干扰”，原资料详细解析可以展开查看。

- 带提示答对计入练习次数和正确次数，但不直接标记已掌握，也不会清除该题已有的错误状态。
- 独立练完一个小课后，可以混合练习这些考点。课程的“已独立练过”表示完成作答，不代表已经全部掌握。
- 带练中答错的题安排在下一个本地日历日复习；当天重做答对仍保留这次复习。到期后，在小白带练中独立答对才会移出清单；再次答错顺延到次日。
- 复习入口会在打开网页时显示，不会在网页关闭后发送提醒。完成阶段、复习日期都随进度备份导出和导入。
- 未答完提前结束不会记为完成课程阶段。正常刷新后，可从首页继续当前阶段。

这些口诀和逐题提示是新增的学习辅助，按明确考点选题；不是覆盖全部 887 道题的万能规则。继续保留原资料的答案、解析和来源。

## 已支持

- 分类练习：交际用语、词汇与语法、虚拟语气、汉译英、英译汉，可多选。
- 筛选来源、打卡天数、具体考点、未做题、错题、收藏、已掌握；搜索题目和考点。
- 顺序或随机抽题；每组 10 / 20 / 30 / 50 题或全部。范围不足时使用全部匹配题，不重复补题。
- 选择题确认后判分并展示原资料解析；翻译题填写译文、看参考答案后自评。
- 背题模式：先回想，再翻开答案，标记已掌握或还需复习。
- 随机测验：交卷前隐藏答案，交卷后统一查看，翻译题需自行评价。
- 错题自动收录，独立答对 / 标记已掌握后移出；小白带练的提示答对不移出已有错题，收藏独立保存。
- 练习位置、作答、错题、收藏和阅读状态通过浏览器 localStorage 保存。
- 128 篇双语阅读，按教材筛选，搜索标题、英文正文或中文译文；忽略大小写和多余空白，支持空格分隔的多个关键词，并展示匹配正文片段。另支持随机阅读、隐藏中文、已读标记。
- 练习记录、近 14 天练习量，进度 JSON 导出 / 导入。
- 适配电脑与窄屏；练习页支持 A–D 和 Enter 快捷键（输入框内暂停）。

## 题库整理

资料文件位于上一级的 `英语刷题/` 和 `阅读理解128文章/`。文件名、资料标题和网页名称统一使用“英语”，题目与阅读正文保留原内容。

| 来源 | 原始条目 | 处理方式 |
| --- | ---: | --- |
| 30 天打卡文件 | 900 | 逐题导入，保留日期与题号 |
| 必刷题复习整理 | 394 | 按原分区导入 |
| 刷题复习汇总 | 900 | 为上述 30 天重复汇编，不重复导入 |
| 8 份 Word 阅读材料 | 128 篇 | 按教材、单元、Reading 拆分 |

1,294 条题目按规范化的题干和选项内容合并（忽略选项顺序），得到 **887 道题**（707 道选择题、180 道翻译题），合并 407 条重复记录。旧版本中因选项顺序不同而保留的重复题，其收藏、做题次数和最新答题状态会自动合并，未完成练习的已选答案按内容转换；旧进度备份同样兼容。每题保留全部来源；来源计数不等于去重后题目数。相近但选项不同的题分开保留。原文件的旧作答与正确率不导入为新网站的个人成绩。

| 分类 | 题数 |
| --- | ---: |
| 交际用语 | 161 |
| 词汇与语法 | 311 |
| 虚拟语气 | 235 |
| 汉译英 | 119 |

原始资料已分区的题目沿用原分类；其他题目根据考点和解析归类。答案、解析以及题干存疑等备注保留原资料内容，未独立校对每题答案。翻译表达不唯一，因此不做字符串比对判分。

未作答 / 未自评的题不进入错题本，不计入正确率。学习记录中的正确率包含选择题结果及自行标记的掌握情况。导入备份会替换当前记录，备份不恢复未结束的练习位置。最近 100 组完成记录保留，累计统计不受此限制。

## 文件与维护

- `打开英语自习室.html`：双击打开的入口，自动进入 `dist/index.html`。
- `启动本地服务.command`：可选的本地服务启动脚本。
- `dist/index.html`：网页入口。
- `dist/styles.css`、`dist/app.js`、`dist/core.js`：样式、交互与筛选/记录逻辑。
- `dist/beginner.js`：7 个小课、逐题提示、阶段与隔天复习逻辑；重新导入题库时保留。
- `dist/data.js`：完整题库和阅读正文，经典脚本加载，支持直接打开本地 HTML。
- `scripts/import_data.py`：从原始材料重新生成数据，使用 macOS 自带的 textutil 读取 Word。
- `scripts/check.cjs`：题库完整性和关键行为检查。
- `data-report.json`：整理数量与答案冲突报告。

重新导入（macOS）：

```sh
python3 scripts/import_data.py
node scripts/check.cjs
```

手动启动服务：

```sh
python3 scripts/serve.py
```

## GitHub Pages 发布

GitHub Actions 在每次推送 `main` 分支时运行 `node scripts/check.cjs`，通过后将 `dist/` 发布到 GitHub Pages。也可在仓库的 Actions 页面手动运行 **Deploy GitHub Pages**。Pages 的发布来源设置为 **GitHub Actions**。

仓库保存已整理的题库数据，因此部署时无需重新解析原始 Word 或 Markdown。需要更新题库时，在本机重新导入并检查，再提交生成的数据。

项目无外部字体、CDN、运行时网络 API 或分析追踪。GitHub Pages 提供静态网页托管，刷题与进度保存在浏览器中；本地文件使用方式仍保留。浏览器清理站点数据会删除本机学习记录，请按需导出备份。
